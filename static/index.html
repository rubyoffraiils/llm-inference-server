does batching actually help?

i've been building a small llm inference server from scratch (decode loop, kv cache, batching, scheduling, etc.) bc i wanted to actually see if batching makes that much of a difference.

the server is tested on 24 short trivia questions and sent all 24 to the server at the exact same time. i ran the same test twice:

  • one request at a time
  • batches of up to 4 requests

same model (qwen2.5-1.5b-instruct), same nvidia a40.

each square below is one request, and it lights up as soon as the answer comes back.

one at a time

everyone waits in line

0.0s

batched

four at a time

0.0s

one at a time: 1.6s
batched: 0.9s

so for this burst of 24 requests, batching finished everything about 1.7x faster.

the bigger difference showed up when i kept the server under sustained load. throughput went from around 8.8 req/s → 18.6 req/s, a little over 2x.

i've been seeing a lot of stuff about jev on x recently so i wanted to play around with it too. i used it as a second router (the part that decides if a question goes to the small model or the big one) and put it up against my own one-line rule. mine did at least as well on accuracy, and it decides in ~0.002ms vs ~180ms for jev, for free.

notes to self:

  • give each experiment its own fresh server. i originally ran the tests against the same process, and whichever one ran second looked noticeably worse.
